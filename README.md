# Huevos Sorpresa — Números 1 al 10

Video infantil vertical 1080x1920, 30 fps, 30 segundos. Estética kawaii asiática/pastel, inspirada en una sensación de animación infantil moderna, sin copiar personajes o marcas.

## Ejecutar
```bash
npm install
npm run start
npm run render
```

El render queda en `out/huevos.mp4`.
